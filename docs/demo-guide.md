# PORTLG Pitch Deck — Demo Guide

## Open the presentation

Use the published URL:

https://blueyellow1.github.io/PORTLG-PDK/index.html

The deck contains 10 slides. Use the on-screen left/right buttons, keyboard arrow keys, Page Up/Page Down, Space, or swipe gestures on a touchscreen to navigate. The full-screen control is available where the browser supports it.

## Suggested presentation order

1. Introduce PORTLG Wallet and Team Wilkris.
2. Explain why alerts alone do not enforce contract execution.
3. Introduce the wallet-connected approach.
4. Demonstrate the Protected Action state illustration.
5. Explain the user-to-chain flow.
6. Open the live wallet demo.
7. Show the contract deployment reference and explorer.
8. Explain the architecture.
9. Distinguish roadmap items from implemented features.
10. Close with the repository and demo video.

## Important demo distinction

The controls on slide 4 simulate active/paused behavior locally in the browser. They are explanatory only and do not submit transactions. For real wallet interaction, use the wallet demo and verify actual transactions through the explorer.
