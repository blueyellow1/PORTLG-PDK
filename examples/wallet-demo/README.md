# Wallet Demo Example

This folder documents how to present the existing PORTLG Wallet demo. The wallet application source remains in the separate [PORTLG Wallet repository](https://github.com/blueyellow1/portaldot-hackathon-2026-portlg-wilkris).

## Walkthrough

1. Open the wallet demo: https://marvelous-pudding-14d30d.netlify.app/
2. Connect using MetaMask.
3. Confirm MetaMask is set to Portaldot V3 Testnet (Chain ID `420420777`).
4. Review the displayed account and tPOT balance.
5. Use only the wallet actions currently available in the live application.
6. Review transaction details in MetaMask before signing.
7. Use the testnet explorer to inspect confirmed transactions.

## Safety and scope

Use testnet tokens only. Never enter a seed phrase or private key into the application. MetaMask is responsible for signing. This guide is not evidence that every browser/device combination has been tested.
